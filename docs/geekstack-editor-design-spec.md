## 2. 全局约束

### 2.1 主题适配红线（P0，最优先修）

- 编辑器**所有**表面必须走 v1.1 语义 token：`--surface-1/2/3`、`--text-1/2/3`、`--border`。禁止任何 `#fff` / `#000` / 编辑器组件自带硬编码色。
- 代码高亮主题必须成对引入：夜用 one-dark 系、日用 one-light 系，随 `data-theme` 切换。
- 现有编辑器库（如 vditor / md-editor-v3 / bytemd）若不支持主题透传，用 CSS 变量覆盖其内部变量；做不到就换库，**白底亮块在暗色页面上不可上线**。

### 2.2 页面栅格

```
容器 max-width: 860px（书写页收窄，不用首页 1180px；正文行宽 ≈ 70 字符）
垂直节奏：区块间距 24px（--space-6）
```

```
页头：返回｜「发帖」标题｜右侧：草稿状态（自动保存于 14:32）
分类 chips（单选，必填）
标题输入（大号，必填）
编辑器卡片（工具栏 / 编辑区 / 状态栏，三模式）
标签输入（可选）+ 摘要（可选，折叠）
操作栏：存草稿（次级）｜发布（主色，右对齐）
```

## 3. 组件规格

### 3.1 页头

- 左：`← 返回`（文字钮，`--text-3`，hover `--text-1`）
- 中：「发帖」用字阶 `--text-2xl`，700
- 右：草稿状态 mono 小字（`--text-3`）：「草稿已保存 14:32」/ 保存中显示「保存中…」；从未保存过则不显示

### 3.2 分类选择（单选 chip 组）

- 形态：描边 chip（`--border` + `--text-2`），高 36px，圆角 6px（v1.1 方角语言，**不用胶囊**）
- **选中态（必须一眼可辨）**：琥珀 12% alpha 底（`--accent-dim`）+ 琥珀字 600 + 琥珀 1px 描边；未选中为中性描边
- 单选；点击已选中的 chip 不取消（分类必填，防呆）
- 必填标记：组标题「分类」后随 `*`（`--error` 色），**不放每个 chip 上**

### 3.3 编辑器工具栏

高度 44px，`--surface-2` 底 + 1px `--border` 底边线。按钮 32×32、图标 18px、`--text-2`，hover `--surface-3`，**全部带 tooltip（文字 + 快捷键）与 `aria-label`**。

```
分组1 标题:   H ▾（下拉选 H2/H3/H4；再点取消）
分组2 行内:   B (Ctrl+B) | I (Ctrl+I) | S 删除线 | ` 行内代码
分组3 块级:   " 引用 (Ctrl+Shift+Q) | ``` 代码块 | • 无序列表 | 1. 有序列表
分组4 插入:   🔗 链接 (Ctrl+K) | 🖼 图片（点击=上传，支持粘贴/拖拽）
分组5 撤销:   ↶ ↷
── 右侧弹性区 ──
?  Markdown 速查（弹出浮层，含本站常用语法 + 快捷键表）
视图切换：分段控件 [编辑｜分栏｜预览]（见 §3.4）
```

- 分组之间 1px 竖线分隔（`--border`）
- 禁用态（如撤销不可用）：40% 透明 + `cursor: not-allowed`

### 3.4 编辑区 · 三模式（核心交互修正）

**默认单栏「编辑」**；分栏/预览是用户主动选择，不是常驻——空内容时的孤立预览滚动条即由此根除。

| 模式 | 行为 |
|---|---|
| 编辑（默认） | 单栏 textarea/code mirror，行宽 860px 内边距 32px，placeholder 见 §4.1 |
| 分栏 | 仅 ≥1024px 视口可选；编辑 | 预览 1:1，中缝 1px `--border`，同步滚动默认开 |
| 预览 | 单栏渲染结果，只读；顶部浮出「返回编辑」 |

- 分栏模式 <1024px 自动降级为「预览」并 toast 提示一次
- 预览渲染样式 = 文章详情页正文样式（同一套 `.prose` 类，行高 1.75，代码块 `--surface-2` 底 + 主题化高亮）

### 3.5 编辑器状态栏

高 36px，`--surface-2` 底 + 1px `--border` 顶边线，`--text-3` 12px：

```
左：字数 128 · 预计阅读 1 分钟        中：草稿已自动保存 14:32        右：同步滚动 [toggle]
```

- 字数按 CJK 字符 = 1、连续英文单词 = 1 计
- 自动保存：内容变更防抖 3s 写 localStorage，每 30s 静默落库；状态栏文案随之更新
- 同步滚动 toggle 仅在分栏模式显示

### 3.6 标签与摘要（可选，折叠）

- 标签：输入 + Enter 生成 chip，最多 5 个；chip 用中性描边（不占琥珀额度）
- 摘要：默认折叠于「展开更多选项」，多行输入 1–120 字，留空自动截取正文首段

### 3.7 操作栏（sticky）

- `position: sticky; bottom: 0`，`--surface-1` 底 + 顶部 1px `--border`，上遮罩渐变 12px
- 左：`存草稿`（次级按钮，描边）；右：`发布`（Primary，琥珀，唯一主色件）
- **发布前校验**：分类已选 / 标题 5–64 字 / 正文 ≥10 字；不过则 inline 报错（字段下方 12px `--error` 文案）+ 首个错误字段聚焦，**不用弹窗**
- 发布中：按钮 loading 态（文字变「发布中…」+ 禁用双击），成功跳转帖子详情

## 4. 交互细节

### 4.1 编辑区空态（placeholder）

```
支持 Markdown，问题贴请附上：环境版本 · 复现步骤 · 期望与实际表现
粘贴或拖入图片可直接上传
```

两行 13px `--text-3`；比现有「正文支持 Markdown...」多给引导，但不堆示例代码。

### 4.2 快捷键

| 键 | 动作 |
|---|---|
| Ctrl+B / I / K | 加粗 / 斜体 / 链接 |
| Ctrl+S | 立即存草稿（状态栏反馈，阻止浏览器默认） |
| Ctrl+Shift+P | 编辑 ↔ 预览切换 |
| Esc | 关闭速查浮层 |

### 4.3 图片上传

- 粘贴 / 拖拽 / 点击三入口；拖拽时编辑区琥珀 1px 虚线框 + 「松开上传」浮层
- 上传中：光标处插入 `[上传中…]()](#) 占位行；成功替换为 `![](url)`；失败保留占位并 inline 报错 + 重试
- 单图 ≤10MB，格式 jpg/png/webp/gif

### 4.4 离开保护

- 内容非空且未发布时路由离开 → 原生确认框「草稿已自动保存，确定离开？」

## 5. 状态表（必须实现，不可省）

| 状态 | 要求 |
|---|---|
| Loading | 进入编辑器先出工具栏 + 编辑区骨架（`--surface-2` 色块微呼吸），不做 spinner |
| Empty | §4.1 placeholder + 右下角「? 速查」常驻 |
| 保存失败 | 状态栏「保存失败 · 点击重试」（可点），不弹窗打断输入 |
| 发布失败 | 按钮恢复可用 + 顶部 inline alert（`--error`）给具体原因 |
| 网络离线 | 状态栏「离线 · 更改已存本地」，恢复后自动续传 |

## 6. 可访问性红线（沿用 v1.1 §8，本页补充）

1. 工具栏全部按钮：`aria-label` + tooltip，Tab 顺序 = 视觉顺序
2. 视图切换分段控件用 `role="tablist"`，预览区 `aria-live="polite"`
3. 分类 chips 用 `role="radio"` + `aria-checked`
4. 校验错误文案与字段用 `aria-describedby` 关联；颜色非唯一载体（必带文字）
5. 44px 触控目标（工具栏 32px 视觉件外包 44px 热区）
