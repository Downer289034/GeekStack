# 品牌更名决策与落地清单（T10.5）

> 决策日期：2026-09-07 ｜ 决策人：PM 与开发者共同确认
> 背景：原项目名"Java & AI 交流社区"将内容边界焊死在两个技术上，显小众。参考 CSDN/掘金"名字泛化、内容聚焦"的成功路径，改为不设技术边界、有社区归属感的名字。**内容定位不变**：Java 与 AI 仍是初始内容聚焦点，只是名字不再设限。

## 一、品牌定义

| 项 | 定案 |

| 英文名 | **GeekStack** |

| 中文 Slogan（主） | 代码江湖的落脚点 |
| 备用 Slogan | 极客落脚，技术常新 |

## 二、范围与不改项（防蔓延）

**改（用户可见的品牌面）：**
1. 前端：`document.title` 兜底值、各路由 meta 标题后缀、MainLayout 顶部品牌字与页脚、LoginView 卡片标题（"JavaAI 社区"→"极客栈"）
2. 仓库 README：品牌名 + 定位一句话 + Slogan
3. GitHub 仓库名：Settings → Rename（如 `GeekStack` 或保留 `Java-AI-Community` 由开发者定，改后同步本机 remote URL，CI 自动跟随）
4. docs/开发进度.md：决策记录加一条（含本次更名理由与日期）

**明确不改（防止改名变重写）：**
- 代码内部标识符一律保留：包名 `com.community`、artifactId `community-backend`、npm 包名 `community-frontend`、库名 `community`、前端 `TOKEN_KEY='community.*'`、路由与 API 路径 `/api/v1/**`——内部代号 `community` 继续作为项目代号使用，品牌只在展示层
- 数据库、表名、接口契约：零改动
- 历史文档（架构与产品规划/任务清单/评审报告）：不回溯改写，属历史记录；仅进度文档决策区记录更名

## 三、验收标准

- [ ] 全站 `document.title` 与页面品牌字样为"极客栈 / GeekStack"，无"Java & AI 交流社区"残留（`grep -r "Java & AI\|JavaAI" frontend/src` 为空）
- [ ] README 品牌更新，GitHub 仓库名与 remote URL 同步（push + CI 绿灯为证）
- [ ] `mvn verify` 与前端 lint/build 全绿（改动虽小仍须验证）
- [ ] 内部标识符零改动（`grep -r "com.community" backend/src` 数量不变）
