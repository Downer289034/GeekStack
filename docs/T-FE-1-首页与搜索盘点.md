# T-FE-1 前端扩充接口与页面盘点

> 产出日期：2026-09-09 ｜ 面向：PM 评审后下发 T-FE-2/3 验收标准  
> 范围：首页聚合 / 搜索 / 标签聚合 / 排行榜——**现状 + 缺口 + 布局建议**  
> 不改代码，仅盘点。

## 一、现有可复用接口（已通电）

| 能力 | 方法/路径 | 鉴权 | 前端现状 | 首页聚合可用性 |
|------|-----------|------|----------|----------------|
| 热帖榜 | `GET /api/v1/hot?size=10` | 公开 | **无调用** | ✅ 直接用作「热榜」区块 |
| 最新/筛选帖子 | `GET /api/v1/posts?current&size&category&sort` | 公开 | 论坛列表已用 | ✅ `sort=latest&size=N` 作「最新帖子」 |
| 帖子分类 | `GET /api/v1/posts/categories` | 公开 | 论坛已用 | △ 聚合页可作筛选 chip，非必需 |
| 最新项目 | `GET /api/v1/shares?current&size&tag` | 公开（仅 PUBLISHED） | 广场已用 | ✅ `size=N` 作「最新项目」 |
| 帖/项目详情 | `GET /api/v1/posts/{id}`、`/shares/{id}` | 公开（HIDDEN 限作者） | 详情已用 | 区块点击跳转即可 |

**热榜响应形态**：`Result<List<PostCardResponse>>`（与论坛卡片同构：`id/title/viewCount/replyCount/isPinned/...`），无独立「热度分」字段——排序由服务端完成，前端按数组下标即可做 1/2/3 徽标。

**缓存约定（后端已有）**：`/hot` 服务端 60s 缓存；T-FE-2 验收还要求前端 60s 内不重复打接口——建议首页三区块统一用「组件级 TTL 缓存 / 模块单例」而非再打后端。

## 二、缺口单（需新后端排期）

### G1. 全文搜索（卡 T-FE-3）

| 项 | 建议契约（供评审） |
|----|-------------------|
| 路径 | `GET /api/v1/search?q=&type=all\|post\|share&current&size` |
| 现状 | **无**搜索 Controller / 无 ES/LIKE 接口 |
| 临时绕行 | 无；广场仅有 `tag` 精确筛选，论坛仅有 `category`+`sort`，**不能**顶替关键字搜索 |
| 优先级 | P0（T-FE-3 阻塞项） |

### G2. 标签聚合页（卡 T-FE-3）

| 项 | 建议契约 |
|----|----------|
| 路径 | `GET /api/v1/tags`（标签云：`name + count`）；列表复用 `GET /shares?tag=` + **帖子侧缺按 tag 滤** |
| 现状 | 项目 `tag` 筛选已有；**帖子无 tags 字段/筛选**；无全站标签目录 |
| 临时绕行 | 仅做「项目标签聚合」可先上；跨帖子标签需后端加字段或放弃帖侧 |
| 优先级 | P1（可分期：先 share-only） |

### G3. 排行榜页（预留）

| 项 | 说明 |
|----|------|
| 现状 | 仅有热帖 `/hot`；无项目热度榜、无用户贡献榜 |
| 建议 | 短期排行榜页 = 热帖榜全屏版（复用 `/hot?size=50`）；项目榜另立 `GET /api/v1/hot/shares`（缺口） |
| 优先级 | P2 |

### G4. 首页聚合辅助（非阻塞）

| 项 | 说明 |
|----|------|
| 批量摘要 | 现有分页接口足够，**不必**新开 `/home/feed` |
| 封面图 | Share 无 cover 字段；T-DESIGN-5.3 用 CSS 占位——首页卡片同策即可 |
| Post 卡片缺 categoryName | 列表仅有 `categoryId`；前端可本地 join categories（论坛已如此）；若要减请求可在 DTO 加 `categoryName`（可选优化，非阻塞） |

## 三、首页聚合布局建议（供 T-FE-2 验收草案）

Hero（T-DESIGN-5.2 已合入）下方三区块，桌面单列纵向 / 平板同构 / 手机堆叠：

```
[ Hero 180px ]
[ 热榜 ]     ← GET /hot?size=5；前三用 gs-hot-rank 徽标
[ 最新项目 ] ← GET /shares?current=1&size=6；卡片样式对齐广场（青标签+封面占位）
[ 最新帖子 ] ← GET /posts?sort=latest&size=5；紫分类标签 + 置顶 warning
```

**交互**：区块标题右侧「查看更多」→ `/forum`（最热）/ `/shares` / `/forum`（最新）。  
**空态**：各区块独立 `n-empty` + 引导（5.4 统一图标后替换）。  
**缓存**：三区块共享一个 `homeFeedCache`（TTL 60s），路由反复进入不重复请求。

**三断点**：

| 宽度 | 热榜 | 最新项目 | 最新帖子 |
|------|------|----------|----------|
| ≥1200 | 单列列表 | 3 列卡片 | 单列列表 |
| ≤1200 | 同左 | 2 列 | 同左 |
| ≤768 | 同左 | 1 列 | 同左 |

## 四、T-FE-3 页面草图边界（待缺口关闭后细化）

1. **搜索页** `/search?q=`：结果分 Tab（全部/帖子/项目）；无接口前不要开工。  
2. **标签聚合** `/tags` → `/tags/:name`：一期可只挂项目 `?tag=`；帖子侧等 G2。  
3. **排行榜** `/rank`：一期 = 热帖榜加长版。
