## 背景

拍板口径：**顶栏/搜索页 = `/search` 找内容；浮层助手 = `/ai/ask` 问答**。避免用户把站内搜索当 Chat，或把助手当列表搜索。

## 范围

1. 盘点并改文案（仅文案/微提示，不大改布局）：  
   - 顶栏搜索框 placeholder / 快捷说明  
   - `/search` 页空态或标题旁一句说明（找帖子/项目/Skill）  
   - 助手浮层入口/欢迎语（问答社区内容，非关键字列表）  
2. 两入口文案互不混用「搜索」「问一下」等易混词；可各保留一短句边界说明。  
3. 截图：搜索页 + 助手浮层各一张，入 `docs/assets/t-fe-search-assistant-copy/`。

## 非范围

- 不改后端 `/search` 或 `/ai/ask` 契约  
- 不做语义搜索、不改广场布局  
- 不改仓库空态（T-REPO-2 已关）

## 验收

1. 肉眼能分清「找内容」vs「问答」  
2. 证据截图 + 独立 commit  
3. 三句话汇报

## 汇报格式

做了什么 / 证据 / 疑问。
