   - **未绑定** OAuth → 说明 + 按钮「去绑定」→ `/settings`

2. 绑定态：优先读设置页同源 oauth 信息（`/me` 或已有 API）；勿再写合并吓人文案。  
3. `loadData`：`fetchProfile` 与 `fetchRepos` 错误分离——repos 失败不整页「用户不存在」。  
4. 非 owner 看到空列表：中性「暂无展示的仓库」即可。  
5. 截图入 `docs/assets/t-repo-2/`（未绑定 / 已绑定无仓，至少两种）。
