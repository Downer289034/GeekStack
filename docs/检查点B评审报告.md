## 四、上线 Go/No-Go：有条件 GO

### 五项硬性条件

| # | 条件 | 状态 | 说明 |
|---|------|------|------|
| 1 | HTTPS | 🔁 方案调整 | 2026-09-07 决策：改用 **Cloudflare 边缘 SSL**（访客→CF 加密，源站经 Tunnel 免公网入口）。原 certbot 方案转为备用。域名可直接在 Cloudflare Registrar 注册（geekstack.io，成本价） |
| 2 | 数据库备份 + 恢复演练 | ✅ 达成 | 每日 03:00 cron，gzip 轮转 7 份；**恢复演练 DRILL_PASSED**（备份→删表→恢复→数据完整） |
| 3 | 安全检查 | ✅ 达成 | 本报告 2.3 节，无 P0/P1 安全问题 |
| 4 | 日志与监控 | ⚠️ 部分 | 日志落盘 20MB×14 天 ✅；**告警缺失**（见 P1-2）；CF Tunnel 自带边缘健康探测可作最低监控 |
| 5 | ICP 备案 | ⏸ 本模式不适用 | 2026-09-07 决策：公测期源站为 WSL2（无大陆服务器、无经营性 Web 托管），**迁入国内云服务器对大陆用户提供服务时本条件立即触发**，届时须先备案再上线 |

### 结论口径
- **技术检查点 B：通过**。MVP 交付质量高于验收基线（42/42 测试、安全零违规、生产实测通过）。
- **2026-09-07 补充决议——公测模式**：用户拍板采用 **WSL2 + Cloudflare Tunnel** 先行公测（零成本、免备案、免公网入口）。此模式定性为**公测（Pre-launch）而非正式 GO**，服务等级受限（家宽网络、单机、稳定性依赖本机持续开机），允许先对早期用户开放验证。
- **公测准入三个强制条件（完成即可开公测）**：
  1. **P1-4 WSL2 空闲关机抑制**（已两次因空闲重启失联，公测模式下这是 P0 级事故源）
  2. **cloudflared 容器化接入 prod compose**（随栈自启、restart 策略、Tunnel token 入 .env 不入 git）
  3. **P1-1 生产库清库重置**（对真实用户开放前，测试数据必须清掉）
- **正式 GO（毕业条件）**：用户量/稳定性诉求上升，或迁国内服务器时 → 触发 ICP 备案 + 源站迁移，完成后重新复核条件 1/5 即正式 GO。

## 四点五、上线模式决策记录（2026-09-07）

- **决策**：公测期源站维持 WSL2，Cloudflare Tunnel 提供公网入口与 HTTPS；域名注册于 Cloudflare Registrar（geekstack.io）
- **否决/推迟的选项**：境外 VPS（快但成本+迁移）；国内服务器+备案（正解但周期 1–3 周，留作毕业路径）
- **已知接受的风险**：家宽禁建站条款（低流量公测可容忍）、WSL2 单点、CF 免费版大陆绕行延迟
- **对 P 清单的影响**：新增 P1-4；P1-2（告警）、P1-3（备份异地化）在公测期仍建议尽快完成；原"HTTPS 待办"与"ICP 待办"按新口径关闭/挂起
