6封面改墨蓝色系（P0 色彩红线）：当前绿色封面与琥珀强调色形成双色相竞争，且与语义色「成功」撞车。封面统一为墨蓝表面 + 项目名首字（Space Grotesk 大字），或首字母 mono glyph；第一张卡可点睛用琥珀 dim。

06 · 全局布局规则

适用于所有页面，与 v1.1 设计规范并行生效
A容器宽度三档：宽 1180px（首页/项目广场）｜中 900px（论坛列表/帖子详情）｜窄 760px（搜索/表单）。全站禁止无 max-width 的满宽内容。
B卡片 vs 列表判据：有封面图/多字段的实体 → 卡片网格（项目）；纯文本流 → 分隔线列表（帖子/搜索结果）。同一页不得混用两种行样式。
C单强调色：绿色封面全站替换为墨蓝色系；琥珀仅出现在 Logo/主按钮/选中态/置顶底色四处（10% 规则）。
D工具栏公式：页面标题(左) + 主操作(右) 一行；过滤 Tab + 排序一行，均用下划线式选中态，不用胶囊底色。
E区块间距：页面区块间 64px；列表行间 0（用 1px 分隔线 + 行内 padding 20px）；网格卡片间 24px。
FHero 高度：≤120px（仅首页），登录/注册页不设 Hero。
