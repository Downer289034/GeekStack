# 极客栈 GeekStack — 前端设计师入职指引（10 分钟版）

> 欢迎！本文档帮你 10 分钟内跑起来，然后自由探索页面。

---

## 一、本地启动

```bash
# 1. 安装依赖（Node 20+）
cd frontend
npm install

# 2. 启动开发服务器
npm run dev
# → 浏览器打开 http://localhost:5173
```

**后端**需要本机运行（否则 API 接口 401）。快速启动：
```bash
cd backend
# 需要 Java 17 + MySQL/Redis（服务器上已跑）
mvn spring-boot:run
```

如果后端没启动，页面仍能打开但 API 调用会失败（不影响视觉走查）。

## 四、设计 token 系统（你需要知道的）

所有可改的视觉变量集中在两个文件：

- **`src/theme/tokens.ts`** — JavaScript token（JS 逻辑消费）
- **`src/theme/tokens.css`** — CSS 自定义属性（样式消费）

**换肤只需改这两个文件**，不碰任何组件。具体说明见下方“tokens.ts 演进历史”部分。

## 五、常见问题

| 问题 | 解决 |
|------|------|
| 页面空白 | 检查后端是否启动（localhost:8080/actuator/health 返回 UP） |
| 登录后不跳转 | 检查浏览器 localStorage 有 community.token |
| Markdown 预览不显示 | md-editor-v3 需要网络加载字体，首次加载稍慢 |
| 页面宽度 < 1024 时布局破 | PC 端优先，最小支持 1024px |
