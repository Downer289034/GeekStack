## 一、本轮交付（3 件，均可直接给前端落地）

### 1. 发帖页（Markdown 编辑器）设计规范 v1.0
**文件**：`docs/geekstack-editor-design-spec.md`

- 基于前端实拍截图诊断 **8 个问题**，其中 P0 一项：**暗色主题下编辑器仍为白底**（theme token 断裂，红线级，必须先修）
- 核心方案：编辑器三模式（默认单栏编辑，分栏/预览为用户主动切换）｜ 工具栏 5 分组 + 全员 tooltip + 快捷键 ｜ 自动保存（3s 防抖）｜ 图片粘贴/拖拽上传 ｜ inline 校验不弹窗
- 附 **9 条验收清单**，可逐条销项

### 2. 登录页视频背景稿 v1.1
**文件**：`docs/geekstack-login-video.html` + 素材仅存 `frontend/src/assets/login-bg.mp4`（docs 不另存副本）

- 素材实测：1280×720 · 4.35s 循环 · 2.7MB（体量适合网页背景）
- 布局：卡片靠右、左侧露出视频主视觉（≤900px 回中）；**不加压暗层**（视频本身为暗调雨夜场景，产品已确认）
- 可读性策略：卡片 94% 实色承担对比度，禁 backdrop-blur（红线）；降级矩阵完整（reduced-motion / 加载失败 / 省流模式 → 墨蓝+微网格静态态）

### 3. 全站背景粒子层组件 GsParticles v1.0
**文件**：`docs/geekstack-particles-bg.html`（含参考实现 + Vue3 挂载方式）

- 定位：站点级氛围层，App 级单实例，canvas fixed 底层——只在留白/页边距/卡片间隙可见，**绝不盖字**
- **双主题适配**：夜 = 琥珀萤火（alpha 0.08–0.28）；日（晨纸）= 暖墨浮尘（alpha 减半 0.05–0.14）
- 性能红线：DPR 封顶 2、页签隐藏即暂停、`prefers-reduced-motion` 不启动、掉帧第一个砍它
- 密度纪律：内容页 56 颗封顶（登录页 70），「一旦被用户注意到就是失败」

## 二、需 PM 知晓的 3 个设计决策

| # | 决策 | 理由 | 影响面 |
|---|------|------|--------|
| 1 | 视频背景不压暗 | 视频为暗调素材，拉黑层会毁掉画面质感；可读性由卡片实色保证 | 若日后换高亮度视频素材，需重新评估对比度 |
| 2 | 登录/注册页锁定夜色 | 视频背景成立的前提是暗环境 | 此页不提供日/夜切换 |
| 3 | 粒子层为纯装饰，禁止交互化 | 氛围层被「注意到」即失败；同时保住性能预算 | 不做鼠标跟随/连线等加戏 |
