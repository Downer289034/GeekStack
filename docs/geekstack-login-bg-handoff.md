# 极客栈登录页背景 — UI 开发交接文档

> 版本：v1.0 ｜ 日期：2026-09-18 ｜ 上游设计稿：`docs/geekstack-login-bg-v2.html`（v2.3.2，视觉还原唯一基准）
> 素材：`docs/assets/login-bg-dusk.jpg`（2848×1600 · q85 渐进式 JPG · 421KB）
> 适用范围：登录 / 注册页（品牌页口径）。**内容页不适用本方案**（内容页维持主规范 v1.1 无光斑纪律）

---

## 1. 方案演进（Why，30 秒版）

| 迭代 | 结论 |
|---|---|
| ~~视频背景~~ | 淘汰。1.7MB+音轨+降级矩阵重；「土」的根因是具象三件套（金光线/蜂窝底纹/玻璃字），不在媒介 |
| ~~CSS 光斑场~~ | 技术路线正确（skillhub.cn 实证：纯 CSS blur 光斑 + 低频漂移），但左侧空洞 |
| ~~SVG 灯笼 ×2~~ | 方向性失败：扁平插画质感天花板够不到照片级 |
| **✅ 实景图视差（当前）** | 老板自制暮色实景图为主体 + 鼠标视差 + 滚动退场 + 暗角 + 萤火粒子 |

**核心原则：高级感 = 大尺度 + 低频率 + 无具象纹理。** 只动 `transform/opacity`，所有动画周期 ≥3s。

## 2. 最终架构（4 层）

```
z-0  bg-par        视差壳：scale(1.2) 常驻 20% 出血，内含 <img>
z-0  vignette      暗角层（压四边不压中心）
z-0  canvas#fx     萤火粒子层
z-1  stage         登录卡片（靠右 + margin-top 20vh 下移）
```

### 2.1 背景图（必读）

- `object-fit: cover` 全屏；**`transform: scale(1.2)` 常驻**——为视差位移预留 20% 出血，任何时刻不得裁出黑边
- 卡片避让：图中品牌字「极客栈」在中偏左（30–45% 横向区间），卡片 `justify-content: flex-end` + 右侧 `8vw` + `margin-top: 20vh`，16:9 实测无重叠
- 素材规格：2848×1600 PNG 原图已压 **q85 渐进式 JPG 421KB**。**仓库只进压缩版**（PNG 4.4MB 原图留档，严禁入库）

### 2.2 鼠标视差

| 参数 | 值 |
|---|---|
| 方向 | **反向**（光标右移图左移，窗景在"远处"的纵深错觉） |
| 最大位移 | ±20px（主层） |
| 跟随 | lerp 0.05/帧——有质量的惯性缓停，**禁止 1:1 硬连** |
| 实现 | 单 rAF 循环读最新目标值写 transform；mousemove listener 必须 `passive: true` |

### 2.3 滚动退场

- 页面下滚时背景图以 **0.05× scrollY** 速率上移，位移与视差叠加后仍需封顶一屏、不露黑边；滚回复位

### 2.4 暗角层

- `radial-gradient` 只压四边不压中心，聚焦桌灯与窗景；**禁止再叠全屏压暗 scrim**（照片自身明暗结构已够，老板明确不要变暗效果）

### 2.5 萤火粒子（全站 GsParticles 的登录页参数）

| 参数 | 值 |
|---|---|
| 数量 | `min(44, 视口面积/34000)`，**封顶 44 颗**（比站点版更收敛，照片自带空气感） |
| 半径 / 透明度 | 0.8–2.2px ｜ α 0.06–0.22（琥珀 `rgba(255,186,100)`） |
| 运动 | 上浮 0.1–0.35px/帧 + 正弦横摆 + 0.9s 明暗呼吸 |
| 硬性 | `pointer-events:none`；DPR 封顶 2；只画 arc 禁 shadowBlur；页签隐藏暂停 rAF |

## 3. 降级矩阵（必须实现）

| 条件 | 行为 |
|---|---|
| `prefers-reduced-motion` | 不启动视差/滚动/粒子，静态图 + 暗角 |
| 触屏设备（无 hover） | 同上，直接不初始化交互 |
| 图片加载失败 | 兜底 `--ink-950` 墨蓝底色（Token 取主规范 2.1） |
| 持续掉帧（90 帧 avg < 50） | 交互全部降级为静态，粒子减半 |

## 4. 红线（验收一票否决）

1. **禁 backdrop-blur**：卡片用 90% 实色 + 投影托层次（叠照片是 GPU 大户 + 主规范红线）
2. **登录/注册页锁定夜色**：主题切换器不进此页；文字只出现在卡片内，图区不承载文字（无需压暗）
3. **禁文字/Logo 外发光**：图中已有品牌字，**前端不得再渲染 HTML 字标**（重复）
4. 性能：视频已下线——如有人想"加回视频背景"，先看本文档第 1 节
5. 视差/粒子**禁交互化**（禁鼠标跟随粒子、禁粒子连线）——一旦被用户注意到就是失败

## 5. Vue3 落地指引

- 建议封装 `<LoginBackground />`（含 img + vignette + canvas 三件）与登录表单解耦；只在登录路由挂载，`onUnmounted` 销毁 rAF 与监听
- 图片 `preload="auto"`；可配合 `new Image()` 预载完成后再进页面转场
- 参考实现（CSS/JS 可整段移植）：`docs/geekstack-login-bg-v2.html`，其中评审开关（视差/粒子）仅用于验收，**不随代码进仓**

## 6. 验收清单

- [ ] 1920×1080 下卡片不遮图中「极客栈」品牌字；任何滚动/视差位置不露黑边
- [ ] 鼠标视差有惯性缓停（lerp 手感），非 1:1 硬连
- [ ] 滚动时图退场速率 0.05×，滚回复位平滑
- [ ] 触屏 / `prefers-reduced-motion` 下为静态图，无任何动画
- [ ] 图加载失败显示墨蓝兜底色，页面可正常登录
- [ ] DevTools Performance：视差+粒子开启时输入交互无阻塞，GPU 增量可感知 ≤3%
- [ ] 仓库内素材仅 `login-bg-dusk.jpg`（≤450KB），无 PNG/视频冗余
