## ⚠️ 环境注意事项（2026-09-07 实测踩坑，后续会话必读）

1. **WSL2 会空闲自动关机**（Ubuntu-24.04 Stopped）→ 服务器 SSH/MySQL 全部失联。恢复：`wsl -d Ubuntu-24.04 -- true` 启动即可；容器配置了 `restart: unless-stopped` 会随 Docker 自动拉起（已验证）。开发库连接 IP 用 `172.25.41.137`（本次重启后 IP 未变；若变，用 `wsl -d Ubuntu-24.04 -- hostname -I` 查新 IP 并更新本机 `.env`）
2. **本机 Windows 装有原生 MySQL 服务（mysqld.exe 监听 0.0.0.0:3306）**→ 严禁用 `127.0.0.1:3306` 当开发库（连的是本机 MySQL 而非 WSL 容器，会报 Access denied）。一律走 `172.25.41.137`
3. **GitHub 访问依赖加速器**：PM 未开加速器时 push/api 会连接重置或超时；遇 `Recv failure: Connection was reset` 先提醒 PM 开加速器再重试
4. **jar 被运行中的后端进程锁定**：Windows 下先停 8080 进程再 `mvn verify/package`，否则 repackage 重命名失败
5. 服务器 MySQL 已补 `'community'@'localhost'` 授权（当时排查 127.0.0.1 误连本机 MySQL 时顺手加的，保留无害）

2. 服务器实为本机 WSL2 → MySQL/Redis 天然仅本机可达，内网隔离成立

4. Checkstyle = google_checks.xml(10.21.4) 变体：行长 120、4 空格缩进、SummaryJavadoc period=。（中文句号），其余保持 Google 原版
5. JDBC URL 用 `characterEncoding=UTF-8`（驱动自动映射 utf8mb4；直接写 utf8mb4 会报错）
6. T7+ 接口测试策略：CI 用 GitHub Actions services 拉起 MySQL/Redis 真跑测试；本地测试连服务器实例
7. Spring 通过 `spring.config.import: optional:file:./.env[.properties]`（及 `../`）读根目录 .env，无需额外依赖
8. **主键用数据库自增（IdType.AUTO）而非 MP 默认雪花 ID**：雪花 ID 超出 JS Number 安全整数（约 9e15），浏览器 JSON 解析精度丢失会导致按 id 查详情 404；T10 起生效（已清库重置自增）
9. **MP 3.5.12 两个坑**（后续任务注意）：① `FieldStrategy.IGNORED` 已移除，改用 `ALWAYS`；② `PaginationInnerInterceptor` 拆分到独立构件 `mybatis-plus-jsqlparser`，需显式引入
10. Markdown 渲染全站唯一出口 `frontend/src/utils/markdown.ts`（markdown-it html:false + DOMPurify），页面禁止绕过；详情页 v-html 处有 eslint 豁免注释说明
11. 前端 naive-ui：`useMessage()` 必须有 `<n-message-provider>` 祖先（已挂在 MainLayout）；`NCard` 无 title 时 `#header-extra` 不渲染
12. 列表排序用 `created_at + id` 双键（created_at 秒级精度，同秒并列需 id 保证确定性）——T11 论坛列表沿用
