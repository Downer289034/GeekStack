## ⚠️ 环境注意事项（2026-09-07 实测踩坑，后续会话必读）

1. **WSL2 会空闲自动关机**（Ubuntu-24.04 Stopped）→ 服务器 SSH/MySQL 全部失联。恢复：`wsl -d Ubuntu-24.04 -- true` 启动即可；容器配置了 `restart: unless-stopped` 会随 Docker 自动拉起（已验证）。开发库连接 IP 用 `172.25.41.137`（本次重启后 IP 未变；若变，用 `wsl -d Ubuntu-24.04 -- hostname -I` 查新 IP 并更新本机 `.env`）
2. **本机 Windows 装有原生 MySQL 服务（mysqld.exe 监听 0.0.0.0:3306）**→ 严禁用 `127.0.0.1:3306` 当开发库（连的是本机 MySQL 而非 WSL 容器，会报 Access denied）。一律走 `172.25.41.137`
3. **GitHub 访问依赖加速器**：PM 未开加速器时 push/api 会连接重置或超时；遇 `Recv failure: Connection was reset` 先提醒 PM 开加速器再重试
4. **jar 被运行中的后端进程锁定**：Windows 下先停 8080 进程再 `mvn verify/package`，否则 repackage 重命名失败
5. 服务器 MySQL 已补 `'community'@'localhost'` 授权（当时排查 127.0.0.1 误连本机 MySQL 时顺手加的，保留无害）
