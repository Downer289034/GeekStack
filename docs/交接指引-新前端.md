**极客栈 GeekStack**——技术社区。技术栈：Vue 3.4 + Vite 5 + TypeScript 5 + Pinia + Naive UI（浅色主题，"鸿蒙设计风"）。

**页面地图**（9 页 / 13 路由）：登录注册（含 GitHub/Gitee OAuth）、项目广场、项目详情/发布（Markdown 编辑器）、论坛列表、帖子详情/发帖、个人主页（含仓库卡片）、通知中心、404 兜底。

**质量现状**：88 后端测试全绿；前端经三轮设计整改（WCAG AA 达标、响应式 375/768/1200 三断点、断点口径入册 `tokens.css` 注释）。

## 三、红线（违反 = 评审退回）

1. **XSS 铁律**：Markdown 渲染全站唯一出口 `utils/markdown.ts`（`html:false` + DOMPurify），**禁止绕过**；新增 `v-html` 必须走 `renderMarkdown` 并留豁免注释
2. **换肤只动 `tokens.ts` + `tokens.css`**，不碰组件；断点 375/768/1200 是全站字面值，新样式不得私定断点
3. 品牌展示一律"极客栈 / GeekStack"（内部代号 `community` 不上界面）
4. 回报必须附 `npm run lint` + `vue-tsc --noEmit` + `vite build` 三绿
5. 动组件结构先报 PM 批范围（纯样式自由）

## 五、即将启动的大活：前端展示扩充（组合方案，老板已拍板）

三个方向一起做，**视觉丰富度提升是老板点名的核心痛点**（"只有白色和蓝色按钮"）：

1. **首页聚合**：热榜 + 最新项目 + 最新帖子聚合进首页（后端已有 `/api/v1/hot` 等接口）
2. **新增页面**：搜索 / 标签聚合 / 排行榜（后端接口需新后端配合，先出页面设计稿评审再开发）
3. **现有页增强**：广场卡片封面/预览、详情页相关推荐、视觉层次（见下）

**视觉丰富度专项（T-DESIGN-5）**：当前界面确实偏素——建议方向：渐变 hero 区、卡片阴影/悬停微动效、多彩语义标签（Token 已支持 success/warning/error 文字变体）、图标体系引入、空状态插画。**先出视觉方案评审，批准后动码**——Token 架构完全撑得住，是"没用够"不是"不够用"。

**分工建议**：UI 先出设计稿（首页聚合 + 视觉方案），前端开发按稿实施；任务拆分与验收标准等设计稿评审后由 PM 下发。
