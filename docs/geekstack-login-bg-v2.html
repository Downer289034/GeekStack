登录背景 v2.3 · 实景图视差（SVG 灯笼下线）

geekstack-login-bg-v2.html ｜ v2.3.2 ｜ 2026-09-18 ｜ 素材：老板自制暮色实景图（docs/assets/login-bg-dusk.jpg · 2848×1600 · q85 压缩后 421KB；PNG 原图 4.4MB 留档不进库）

1. 决策记录：为什么放弃 SVG 灯笼

  • 两轮迭代结论（v2.1 悬挂灯笼 / v2.2 重雕放大）：手绘 SVG 再怎么加骨架、柱面渐变、轮辋光，质感天花板就是扁平插画——与登录页要的「夜宿实感」不在一个层级，判定为方向性失败，果断下线
  • 实景图的优势：摄影级景深（桌灯实光影、窗外暮色焦外）、品牌字已按构图烙印在图中、素材零成本（老板自制）
  • 历史包袱清理：orbs 光斑 / 灯笼 defs / 字标 HTML 全部移除——图中已有品牌字，HTML 字标再渲染一遍是重复

2. 图层栈与视差参数

层参数
① 实景图（视差壳）scale(1.2) 常驻——预留 20% 出血，鼠标/滚动位移永远裁不出边｜ 鼠标反向漂移 ±20px·±14px（图与光标反向 = 窗景在「远处」的纵深错觉）｜ 滚动 0.05x scrollY 上移（封顶一屏），离场感｜ 目标值 lerp 0.05/帧，带质量惯性
② 暗角 vignetteradial 四边 38% + 底部 30%，只压边缘不压中心——聚焦桌灯与窗景，卡片区域再叠自身 90% 实色
③ 萤火粒子全站 GsParticles 降档（α 0.06~0.22·44 颗封顶）——照片自带空气感，粒子只补「活气」
④ 登录卡片靠右 + margin-top 20vh 下移：避让图中右上品牌字（16:9 桌面实测不遮挡）｜ 卡片 90% 实色 + 大投影托层次，禁 backdrop-blur（叠照片是 GPU 大户 + v1.1 红线）

3. 素材与生产化要求（重要）

  • 分辨率：v2.3.2 已换 2848×1600 原图（PNG 4.4MB 已压 q85 渐进式 JPG · 421KB 入库），4K 屏覆盖无压力，分辨率事项关闭
  • 建议出「无字版」底图：品牌字烙在图里意味着换语言/改品牌就要重做图——生产建议底图不带字，极客栈 / geekstack 用 HTML 叠加渲染（任意分辨率锐利、可国际化、可做入场动效）
  • 加载策略：图仅在登录/注册路由加载；preload + 骨架底色 --ink-950 兜底，图未到时页面不白屏

4. 性能门控（沿袭 v2.2 全套）

  • 单 rAF 循环全包（mousemove passive，无 scroll 监听——每帧读一次 scrollY）；持续掉帧（>34ms × 90 帧）自动降为隔帧更新；页签隐藏即暂停
  • 触屏（pointer:coarse）与 prefers-reduced-motion 不启动视差：图静止在 scale(1.2)，粒子不启动——装饰退回纯氛围
  • 只动画 transform（GPU 合成层）；暗角/卡片全是静态层，零逐帧成本

5. 验收清单

  • [ ] 鼠标左右缓移：窗景与桌灯整体反向轻漂（≤20px），松手带惯性缓停，无硬连感
  • [ ] 滚动到规格区：图缓慢上移退场（0.05x），滚回复位；任意时刻四边不露黑边（20% 出血验证）
  • [ ] 16:9 桌面：卡片不遮图中「极客栈 / geekstack」品牌字（卡片顶缘在品牌字下缘之下）
  • [ ] prefers-reduced-motion / 触屏：视差与粒子全关，图静止，无任何运动
  • [ ] 视差开关关闭后 transform 复位，无残留偏移
  • [ ] 弱网模拟：图未加载时背景为墨蓝底色 + 卡片可用，无白屏闪烁
