# T14.6 联调样例

> 前置：后端 `mvn spring-boot:run` 已启动；本机 `.env` 已含 `STEWARD_WEBHOOK_SECRET`；Agent PM 已持有相同密钥并启动 Agent。

## 联调用用户

```bash
# 注册（取 token）
TOKEN=$(curl -s -X POST http://localhost:8080/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"t146_user","email":"t146@test.local","password":"password123"}' \
  | grep -o '"accessToken":"[^"]*"' | cut -d'"' -f4)
```

## 样本 A：5000+ 字符帖子（测 truncated 路径）

```bash
# contentText 约 6000 字符 → 应被截断为 5000 + truncated=true
LONG_BODY=$(python3 -c "print('测试内容重复填充 ' * 400 + ' 结尾')")
curl -s -X POST http://localhost:8080/api/v1/posts \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d "{\"categoryId\":1,\"title\":\"T14.6 截断路径测试\",\"contentMd\":\"$LONG_BODY\"}" \
  | python3 -m json.tool | head -5
```

**Agent 侧验证**：
- 收到 `contentId=post_xxx`、`contentType=post`
- `contentText` 长度 ≤ 5000
- `metadata.truncated = true`
- body 包含"测试内容重复填充"但总长不超过 5000

## 样本 B：普通帖子（AI 分类）

```bash
curl -s -X POST http://localhost:8080/api/v1/posts \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"categoryId":2,"title":"T14.6 普通帖子样本","contentMd":"AI分类帖子正文。"}'
```

## 样本 C：项目分享

```bash
curl -s -X POST http://localhost:8080/api/v1/shares \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"T14.6 分享样本","summary":"联调用项目分享","contentMd":"# 项目介绍\n\n联调用分享。","tags":["Java","Spring"]}'
```

## 样本 D：帖子评论

```bash
# 取任意帖子 ID
POST_ID=1  # 替换为实际 ID
curl -s -X POST "http://localhost:8080/api/v1/posts/$POST_ID/comments" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"contentMd":"T14.6 联调评论样本"}'
```

## Agent 侧预期

| 样本 | content_type | content_text | truncated | metadata.target_type |
|------|-------------|-------------|-----------|---------------------|
| A（长帖） | post | ≤5000字符 | true | post |
| B（普通帖） | post | 帖子正文 | false | null |
| C（分享） | share | 项目介绍… | false | share |
| D（评论） | comment | 联调评论样本 | false | post |

## 联调成功标志

1. Agent 侧收到四个事件，各自返回 202 + `trace_id`
2. 极客栈侧日志：`Webhook 推送成功: contentId=post_xxx, localTrace=wf-xxx, agentTraceId=wf-xxx`
3. 双方日志的 `agentTraceId` 一致 → 对账链路通
