登录页 · 视频背景实现规格

geekstack-login-video.html ｜ v1.0 ｜ 2026-09-11 ｜ 上游：geekstack-ui-design-spec.md v1.1

1. 视频层

项要求
素材frontend/src/assets/login-bg.mp4（设计稿经相对路径引用；入库版 ≤1.7MB、去音轨；docs/assets 不再保留副本）
属性（必写全）autoplay muted loop playsinline disablepictureinpicture——缺 muted playsinline 会被浏览器拒绝自动播放
铺排object-fit: cover 全屏铺排；aria-hidden="true" tabindex="-1"（纯装饰，对辅助技术隐身）
加载策略视频仅在登录/注册路由加载（组件挂载时才插 <video>，路由离开即销毁）；preload="metadata"，不要 auto

2. 布局与可读性（不压暗视频）

  • 卡片靠右：.stage 用 justify-content: flex-end + 右侧 8vw 内边距，左侧完整露出视频主视觉；窄屏 ≤900px 卡片回中
  • 不加压暗 scrim（产品决策）：视频为暗调雨夜场景，可读性完全由卡片 94% 实色承担；文字只出现在卡片内，视频区不承载文字
  • 日后若换高亮度视频素材：优先换暗调素材，其次才恢复轻量 scrim——禁止靠拉黑视频换对比度

2.5 粒子流层（灯笼萤火）

参数取值说明
层序video → canvas → 卡片粒子叠在视频上、卡片下；pointer-events: none 不挡交互
数量min(70, 面积/22000)随视口自适应，封顶 70——氛围层不许喧宾夺主
运动上浮 0.12–0.42px/帧 + 正弦横摆 ±0.12px萤火上升 + 微风摆动；周期 2.4s，避免匀速机械感
外观半径 0.8–2.6px · rgba(255,186,100) · alpha 0.08–0.28琥珀微光 + 0.9s 呼吸闪烁——属氛围光，不计入琥珀 3 处纪律额度
性能DPR 封顶 2 · 只画 arc 无阴影/模糊4K 屏不烧 GPU；visibilitychange 页签隐藏即停
降级prefers-reduced-motion → canvas 直接不插入降级态（墨蓝+网格）同样保留粒子；两者独立开关
优先级性能掉帧时第一个砍掉的就是这层纯装饰，视频 > 粒子 > 一切交互的优先级次序不可变

3. 红线（沿用 v1.1，视频背景下重申）

  • 禁 backdrop-blur：卡片用 94% 不透明实色（oklch(20% 0.02 262 / 0.94)），不用毛玻璃——blur 叠视频是 GPU 大户且违反主规范
  • 琥珀纪律：本页仅 3 处——Logo、Tab 下划线选中态、登录主按钮 + 输入框焦点环；OAuth 按钮、文案全部中性
  • 登录/注册页锁定夜色：视频背景成立的前提是暗环境，日/夜主题切换器不进此页

4. 降级矩阵（必须实现）

场景行为
prefers-reduced-motion不插 video，直接降级态（墨蓝 + 微网格），无任何动画
视频加载失败 / <3G / save-data同上降级态；<video> 的 error 事件与 navigator.connection.saveData 都要接
移动端 ≤768px建议直接用降级态（省流量省电）；若产品坚持要视频，最多播 1 轮后停在末帧（loop 移除 + ended 暂停）
降级态样式ink-950 底 + 48px 微网格线（25% alpha），无 scrim——截图里原版「纯黑一整块」就是没有这层网格质感才显得平

5. 可访问性

  • 视频对辅助技术完全隐身：aria-hidden + tabindex="-1"，不进 Tab 序
  • 输入框焦点环：琥珀 1px 边 + 3px 14% alpha 光环（全站统一口径）
  • Tab 等宽 50%、role=tablist/aria-selected、44px 触控目标——与主规范 §8 一致

6. 验收清单

  • [ ] 视频自动播放且无声（系统音量开大验证）
  • [ ] 视频原样播放无压暗；卡片内文字在任何视频帧下对比度 ≥4.5:1（由卡片实色保证）
  • [ ] 关掉视频（降级态）页面依然完整可用、好看
  • [ ] prefers-reduced-motion 下无视频无动画
  • [ ] 仅登录路由加载视频，离开后网络面板无持续请求
  • [ ] DevTools Performance：视频播放不掉帧、不阻塞输入交互
  • [ ] 粒子层叠加不遮挡任何输入交互（pointer-events 实测），页签切走后 rAF 停止
  • [ ] prefers-reduced-motion 下无视频无粒子无动画
