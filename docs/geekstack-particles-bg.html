全站背景粒子层 · 集成规格

geekstack-particles-bg.html ｜ v1.0 ｜ 2026-09-18 ｜ 上游：geekstack-ui-design-spec.md v1.1

1. 挂载方式（Vue3，全站唯一实例）

// src/components/GsParticles.vue —— App.vue 里挂一次，路由切换不重建
<template>
  <canvas class="gs-particles" aria-hidden="true"></canvas>
</template>

// App.vue
<GsParticles />   ← 放在 <router-view/> 之前，fixed 底层
// CSS：.gs-particles { position: fixed; inset: 0; z-index: 0; pointer-events: none; }
//      #app 内容容器 z-index: 1（或各布局组件自带层叠上下文即可）

2. 双主题配色（随 data-theme 切换，每帧读一次 dataset.theme）

主题粒子色alpha气质
夜（默认）rgba(255,186,100) 琥珀0.08–0.28灯笼萤火，呼应「灯」
日（晨纸）rgba(150,118,72) 暖墨0.05–0.14纸上浮尘，降到几乎不可见但不至于死板

3. 参数（与登录稿 2.5 节同源，站点模式略收敛）

参数取值
数量min(56, 面积/26000)——内容页比登录页更收敛（56 vs 70），避免在正文页抢注意力
运动上浮 0.1–0.36px/帧 + 正弦横摆 ±0.1px，周期 2.4s；0.9s 呼吸闪烁
尺寸半径 0.8–2.4px；DPR 封顶 2
层序canvas fixed z-0 → 站点内容 z-1；粒子只在留白/页边距/间隙可见，绝不盖字
生命周期App 级单实例；visibilitychange 暂停；prefers-reduced-motion 不启动
优先级性能预算最低位：掉帧先砍粒子，再砍视频类，最后才动内容

4. 红线

  • 粒子是氛围层不是内容层：不允许加鼠标跟随、不允许加连线、不允许放大加亮——一旦被用户「注意到」就是失败
  • 琥珀粒子不计入琥珀 3 处纪律额度（同登录稿口径），但日间主题 alpha 必须减半，晨纸上不许出现明显色块
  • pointer-events: none 与 aria-hidden 必写——不挡交互、不进辅助技术树
  • 登录/注册页若也启用，沿用其独立稿参数（70 颗版）；两处共用同一组件，用 prop 区分密度

5. 验收清单

  • [ ] 日/夜主题切换粒子配色跟随，日间 alpha 明显更收敛
  • [ ] 粒子只在留白区可见，正文、卡片表面之上无粒子
  • [ ] 长列表滚动、路由切换不掉帧（Performance 面板 GPU 占用增量 <3%）
  • [ ] 页签切走 rAF 停止，切回恢复
  • [ ] prefers-reduced-motion 下无粒子
  • [ ] 键盘 Tab 巡检：粒子不进焦点序
