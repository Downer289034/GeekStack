1. **SSH 免密登录**：本机生成/复用密钥，用临时 askpass 脚本一次性把公钥写入服务器 `authorized_keys`，随后立即删除该临时文件；此后全程密钥免密。密码不写入任何文件/命令历史/仓库，后续回复中也不再复述。
2. **服务器基础设施**：探测服务器现有环境（Docker/MySQL/磁盘内存）；缺 Docker 则用 apt 安装；用 Docker Compose 拉起 **MySQL 8（utf8mb4，建库 community）+ Redis 7**，数据卷持久化，密码等凭据放在服务器本地 `.env`（不入 git），仅监听内网。
3. **本机工具链检查**：核验 JDK17 / Maven 3.9+ / Node 20+ / git，缺失项用 winget 或官方安装包补齐（若安装被权限拦截则报告并给替代方案）。
4. **git 仓库初始化**：monorepo `git init` + `.gitignore`（node_modules/target/.env/dist 等）+ 首次提交（docs 入库）；创建 **`docs/开发进度.md`**（AGENTS.md 轮回会话机制：记录已完成任务、关键决策、下一步，每完成一个任务更新，上下文将满时以此衔接下一轮会话）。
5. **GitHub 远程**：到达 T6 时引导你创建 GitHub 仓库并推送（需要你的账号授权；在此之前只做本地提交，不阻塞 T1–T5）。

  验证：启动时 migrate 一次通过，表结构与索引核对无误。
